ChipTune

Личная программа для Windows: архив файлов мастерской по чип-тюнингу с обменом между своими ноутбуками через Google Диск пользователя. Программа не продаётся и не распространяется публично.

English

A private Windows program: a chip-tuning workshop's file archive, synced between the user's own laptops through the user's Google Drive. It is not sold or publicly distributed.
